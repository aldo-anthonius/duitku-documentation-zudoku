To use the standardized API by SNAP, merchants need to obtain approval from ASPI in the form of a recommendation letter. To receive this letter, merchants must conduct a developer site test and functionality test.

## SNAP Registration at Duitku

1. **Developer Site Test:** This test is conducted on the ASPI page to ensure that the API complies with SNAP's technical and security standards. Merchants must register on the [registration page at ASPI](https://apidevportal.aspi-indonesia.or.id/sign-up). Merchants can perform the test by following the [developer site test guideline](https://apidevportal.aspi-indonesia.or.id/pedoman/ASPI%20-%20Pedoman%20Pengelolaan%20Developer%20Site.pdf) on the ASPI website. The developer site test includes at least 1 positive test scenario and 1 negative scenario for each sub-API used.
2. **Functionality Test:** Once the developer site test results meet the standards, merchants can proceed with the provided [Functionality Test](#). The functionality test is conducted to test the SNAP API components that have been integrated with Duitku end-to-end.

Before starting SNAP integration, you need to register for SNAP at Duitku. Please send the public key, information, and required documents using the email registered with Duitku to **[info_tech@duitku.com](mailto:info_tech@duitku.com)**.

You need to send **2 separate emails** to Duitku. To facilitate the registration process, you must use **the primary email registered with Duitku**. Below are the information and documents you need to attach when sending these emails:

### First Email:

1. **API Services.** The API services provided by Duitku:
   * Transfer Intrabank (H2H)
   * Transfer Interbank (RTOL)
   * Transfer BI-Fast
   * Transfer SKNBI
   * Transfer RTGS
   * E Wallet Top Up
2. **Zip file containing Public Key** in `.pem` format and protected by a password. For instructions on creating a public key, refer to the Public Key and Private Key guidelines below.

### Second Email:

1. Password to open the zip file containing the public key sent previously.
